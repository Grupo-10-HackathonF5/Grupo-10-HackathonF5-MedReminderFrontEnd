# MedReminder

MedReminder is a web application designed to help users manage their medication schedules in a simple and accessible way.
The app allows patients or caregivers to register medications, schedule intake times, and keep track of doses taken throughout the day.

Built as part of Hackathon F5 – September 2025, this project focuses on good development practices, scalable architecture, and an intuitive user experience.

## How It Works

Users can:

- ✅ Register medications
- ✅ View active medications grouped by time of day
- ✅ Mark doses as taken and track progress for the day
- ✅ Edit or delete registered medications

## How to Run the Project Locally

Frontend:

```bash
# 1. Clone the repository
git clone https://github.com/Grupo-10-HackathonF5

# 2. Move into the project directory
cd Grupo-10-HackathonF5

# 3. Install the dependencies
npm install

# 4. Install react-router-dom version 6
npm install react-router-dom@6

# 5. Start the development server
npm run dev

```
